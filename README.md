# Trek Nepal with Ganesh

Website for Ganesh, a licensed trekking guide in Nepal (Annapurna, Manaslu, Everest Base Camp, plus Chitwan and Pokhara trips).

Plain static HTML/CSS, no build step. Hosted on GitHub Pages from `main`, root folder.

## Editing

- Text: `index.html`
- Colors, layout and the trek-card backgrounds: `styles.css`
- Photos: `images/` (resize to about 1400 px on the long side before adding)
